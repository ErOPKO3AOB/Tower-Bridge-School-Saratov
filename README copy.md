# «Оранжевый слон» — сайт детского центра

Готовый локальный проект на React, TypeScript, Vite, Tailwind CSS, Motion и Lucide. Дизайн, адаптивная вёрстка, 15 направлений, подбор по четырём вопросам, фильтры, 53 строки реального прайса, отзывы, галерея с просмотром, видео, FAQ и контакты.

## Запуск

Нужен Node.js 22.12+ (проверено на 24.22).

```sh
npm install
npm run dev
```

Откройте URL, который напечатает Vite, обычно http://127.0.0.1:5173. `/api/lead` работает в том же процессе. База данных и ключи не нужны.

```sh
npm run lint
npm test
npm run build
npm run preview
```

`preview` также подключает серверную обработку формы. `npm run build` создаёт `dist/`.

Для запуска собранного сайта вместе с API:

```sh
npm run build
npm start
```

Адрес: http://127.0.0.1:3000. Сервер рассчитан на размещение за HTTPS reverse proxy. При копировании только `dist/` на статический хостинг необходимо отдельно развернуть `/api/lead`: браузер не подменяет серверную отправку фиктивным успехом.

## Обновление контента

Меняйте данные в `src/content`, затем выполняйте `npm run lint` и `npm run build`. Компоненты редактировать не нужно. Изображения задаются номером локального файла `photo-N.webp`. При замене фото обновите `alt` в галерее и исходный URL в аудите. Дата прайса находится в `prices.ts`; сводные цены и дата в интерфейсе обновляются автоматически. Подписи сводных карточек можно изменить в `src/content/pricingSummary.ts`.

Для новых направлений следуйте интерфейсу `Program`; `priceName` должен совпадать с началом названия направления из прайса. Для предметов 1–5 классов возраст в подборе ориентировочный, класс нужно уточнить при записи. Квиз показывает сначала совпадения по интересу, затем другие варианты подходящего возраста/формата. Если их нет, предлагает помощь администратора. Подбор не является диагностикой.

Прайс не содержит предположений о числе уроков или сроке программ. Годовой формат назван годовым только там, где это прямо указано в источнике.

## Форма и demo-режим

`POST /api/lead`, JSON `LeadPayload`. Клиент и сервер проверяют телефон, согласие, обязательные поля, размеры текста и UTM. У формы есть форматирование номера, ошибки, блокировка повторной отправки, honeypot, `aria-live` и нативный доступный `dialog`.

`MockLeadProvider` хранит не более 100 заявок в памяти до 15 минут; данные очищаются таймером и при перезапуске. Файл с персональными данными не создаётся. В журнал попадают только id, статус и имя провайдера. Повтор с тем же `requestId` возвращает тот же id. Ограничение: 10 запросов в минуту на IP, максимум тела — 16 KiB, проверка same-origin для браузерных запросов.

Демонстрационный успех **не означает запись в центр**: это явно указано до и после отправки. Для настоящей записи есть телефон, VK и WhatsApp.

## Будущая интеграция MAX

Скопируйте `.env.example` в `.env`. В Vite переменные читаются только серверной конфигурацией, production-сервер читает `.env` через Node. Никакие значения `MAX_*` не импортируются браузерным кодом.

| Переменная | Назначение |
|---|---|
| `LEAD_PROVIDER` | `mock` по умолчанию; `max` только после реализации транспорта |
| `MAX_BOT_TOKEN` | Секретный токен официального бота |
| `MAX_CHAT_ID` | Идентификатор чата, куда бот имеет право отправлять сообщения |
| `PORT` | Порт production-сервера, по умолчанию 3000 |
| `SITE_URL` | Будущий HTTPS-домен для генерации SEO-файлов |

У владельца нужны: бот и доступ к его управлению, токен, целевой chat_id, добавление бота в этот чат с правом отправки, подтверждение формата уведомления и обработки персональных данных. Одного контактного номера телефона для API недостаточно.

`MaxLeadProvider` намеренно содержит TODO и возвращает ошибку, пока транспорт не реализован. Даже с указанными переменными он **не сообщает о доставке** без ответа реального API. При подключении необходимо реализовать серверный метод `send`, обработку ошибок/таймаутов, проверить актуальную документацию MAX, заменить demo-тексты и обновить политику. Токены нельзя называть с префиксом `VITE_`, помещать в `src/`, Git или `dist/`.

## Аналитика и маршруты

События `center:analytics` передаются через `window.dispatchEvent`, без реального счётчика, персональных данных и внешних запросов. Названия: `quiz_start`, `quiz_complete`, `lead_open`, `lead_success`, `lead_error`, `route_open`, `phone_click`. UTM сохраняются до конца сессии, имена и телефон в browser storage не записываются.

Карта загружается только по ссылке в 2ГИС. Deeplink отмечает центр как пункт назначения. Текстовый адрес отправления пользователь вводит в поле «Откуда» уже в 2ГИС; сайт сохраняет введённую подсказку на экране, не делает вид, что геокодирует адрес, и не рассчитывает время поездки без API. Формат ссылки проверен по [официальной документации 2ГИС](https://help.2gis.ru/question/razrabotchikam-zapusk-ideystviya-vmobilnom-prilozhenii-cherez-deeplink).

## SEO и публикация

После получения домена:

```sh
npm run seo -- https://your-real-domain.ru
npm run build
```

Скрипт обновит `robots.txt`, `sitemap.xml`, canonical, `og:url` и абсолютный `og:image`. До выбора домена sitemap намеренно пустой: фиктивный домен не выдуман. JSON-LD содержит только подтверждённые контактные сведения. Внешние счётчики, CMS и тяжёлая карта не подключены.

Перед публикацией владелец должен подтвердить:

1. Права на фото/видео и согласия на изображения детей.
2. Цены, расписание, длительность программ и число посещений, если их требуется указать.
3. Название остановки: исходные данные говорят «Сапёрная», старый кэш 2ГИС — «Торговый Центр». Парковка не означает гарантию свободного места.
4. Реквизиты и контакты оператора данных, окончательную политику и согласие. Текущая `/privacy` честно описывает demo-обработку.
5. Домен, HTTPS-хостинг с API, реальные уведомления и резервный способ обработки обращений.
6. Мобильный Safari на физическом iPhone: WebKit в этой Windows-среде не запускается.

## Проверки

```sh
npx playwright install chromium
npm run dev
# В другом терминале:
npm run test:e2e
```

Playwright проверяет Chromium на 320×568, 360×800, 375×667, 390×844, 430×932, 768×1024 и 1440×900; горизонтальную прокрутку, квиз, направление в форме, UTM, ошибки, успешную отправку, фильтры, 53 цены, галерею, FAQ, меню и серверную валидацию. Отдельно `npm test` проверяет полноту прайса и границы подбора. Отчёты и снимки находятся в `docs/`.

Опционально: `npx playwright install webkit`, затем `npm run test:webkit`. Здесь процесс WebKit завершался с кодом 3236495362 до открытия страницы; это ограничение окружения, не пройденный Safari-тест. Не выдавать Chromium device-size эмуляцию за тест на реальном iOS.

Проверка обычных ссылок: телефон — `tel:`, VK/WhatsApp — адреса из карточки центра, 2ГИС — оригинальная карточка и официальный формат маршрута. Внешний сайт может потребовать вход или быть недоступен в конкретной сети.
